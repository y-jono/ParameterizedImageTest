# ADR-0010: 機密の仕様出典を匿名化

- Status: Accepted
- Date: 2026-06-24

## Context
入力サンプルは実在アプリの操作ガイドの1ページで、製品名や具体的な文書ID（ファイル名・ページ番号・
ページ表題）が企業機密に触れる。ユーザーから明示的に「製品名を使わない」「具体的な出典を匿名化する」要望。

## Decision
- 出力・ドキュメント・生成物に **製品名や具体的文書ID を残さない**。
- 入力は汎用名で参照（`specs/spec_sample.pdf`、"画像ファイル仕様ページ"）。
- 転記（A-1）では原文中の製品名を `（アプリ名）` に置換し、それ以外の文言は原文どおり保持。

## Alternatives considered
- 原文そのまま保持: 機密漏えいリスク。却下。

## Consequences
- リポジトリ内に機密識別子が残らない。
- 仕様の技術的内容（JPEG/TIFF/RGB/CMYK 等の一般的用語）はテスト設計に必要なため保持。
- 本方針はセッション記憶にも残し、以降のセッションでも遵守する。
