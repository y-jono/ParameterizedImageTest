# ADR-0001: 3段パイプライン＋人間レビューゲート

- Status: Accepted
- Date: 2026-06-24

## Context
画像レイアウトアプリの保守で、仕様に基づく入力画像を網羅的にテストしたい。
手作業では組合せ爆発し網羅性も担保できない。一方、仕様読解→パラメータ化→組合せ→画像生成を
1つのブラックボックスで全自動化すると、誤りの混入箇所が分からず、レビューも不能になる。

## Decision
**仕様ドキュメント → テストパラメータ(1次) → ディシジョンテーブル(2次) → 入力画像(3次)** の
**3段パイプライン**にする。各段は **人間がレビュー・編集できる中間成果物** を出力し、その成果物が
次段の入力になる（レビューゲート方式）。

- A: doc → `parameters.yaml`
- B: `parameters.yaml` → decision table 群
- C: decision table → 画像 + 検証

## Alternatives considered
- 一括全自動（doc→画像）: 速いが誤り箇所の特定・レビューが不能。却下。
- 完全手作業: 正確だが網羅性・スケールが出ない。却下。

## Consequences
- 各段の成果物が独立にレビュー可能。誤りの局所化ができる。
- 段ごとに最適なツール/手法を選べる（A=LLM, B=組合せ, C=画像）。
- 段間の I/O 契約（YAML/CSV）を安定させる必要がある。
