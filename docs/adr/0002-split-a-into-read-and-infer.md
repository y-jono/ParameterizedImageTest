# ADR-0002: A を「読み取り(A-1)」と「因果推論(A-2)」に分離

- Status: Accepted
- Date: 2026-06-24

## Context
A（doc→テストパラメータ）を1段にすると、`parameters.yaml` が誤っていたとき、原因が
「ドキュメントを読み間違えた」のか「読めてはいるが推論/モデル化を誤った」のか切り分けられない。
ユーザーはレビュー時に問題箇所を特定しやすくしたいと要望。

## Decision
A を 2 段に分離し、それぞれ独立した成果物とレビューゲートを持たせる。
- **A-1 読み取り**: ページを **忠実に転記**（推論禁止）→ `out/1a_extract/raw_extract.md`。レビュー観点＝「正しく読めたか」。
- **A-2 因果推論**: 転記からパラメータ因果モデルを導出 → `out/1b_parameters/parameters.yaml`。レビュー観点＝「正しくモデル化できたか」。

## Alternatives considered
- A を 1 段のまま: シンプルだが誤りの切り分け不能。却下。

## Consequences
- 誤読 vs 推論ミスを切り分けてレビューできる。
- プロンプトも `prompts/a1_read.md`（転記）と `prompts/a2_infer.md`（推論）に分離。
- 中間ファイルが1つ増える（許容）。

## 実装メモ
`a1_read.md` は推論禁止・取りこぼし禁止を明示。A-2 出力は ADR-0004 の DSL で記述し、
`a2_lint.py`（ADR-0007）で機械検査してからレビューに回す。
