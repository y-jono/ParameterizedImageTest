# A-1 読み取りプロンプト（忠実な転記・推論禁止）

あなたは仕様ドキュメントの **転記係** です。渡されたページ画像に **書いてあることだけ** を
そのまま書き出してください。**推論・要約・補完・解釈は一切禁止** です。

## 入力
- 仕様ページの画像（`out/1a_extract/<doc>-N.png`）

## 出力
- `out/1a_extract/raw_extract.md` に Markdown で転記。

## ルール
1. ページ上の見出し・箇条書き・表・注記を、**原文の文言のまま**書き写す。
2. 「使用できる画像ファイル」「使用できない画像ファイル」などの一覧は、**項目を1つも漏らさず**写す。
   括弧内の補足（例: `(RGBモード) 8bit`, `(Windows は QuickTime ...)`）も省略しない。
3. 「重要」「参考」「注意」などの注記ブロックも、見出しを付けてそのまま写す。
4. 読み取れない・自信がない箇所は、勝手に埋めず `（判読不能: ...）` と明記する。
5. パラメータ化・分類・因果づけは **行わない**（それは A-2 の仕事）。

## レビュー観点（このファイルを人が確認する際）
- 誤読がないか／一覧の取りこぼしがないか／原文の表現が保たれているか。
